# 🎡 TikTok Live Roulette - لعبة روليت تيك توك لايف التفاعلية

نظام متكامل واحترافي مخصص لبثوث تيك توك المباشرة (TikTok Live) وشاشات البث (OBS / Streamlabs / TikTok Live Studio) مع ربط مباشر بحساب التيك توك وتكامل TikFinity.

---

## ⚠️ القاعدة الأساسية للعبة

> **مدير البث هو الذي يتحكم في تشغيل عجلة الروليت.**
> عندما تتوقف العجلة على رقم لاعب معين، فإن **صاحب هذا الرقم هو الوحيد الذي يحصل على حق اختيار لاعب آخر لإقصائه**، وذلك عن طريق كتابة رقم اللاعب المستهدف في شات TikTok Live.
> **العجلة تختار الشخص الذي سيقرر الإقصاء، وليس الشخص الذي سيتم إقصاؤه.**

---

## 🌟 المميزات والمكونات الرئيسية

1. **ربط مباشر بحساب البث على TikTok**:
   - خانة مخصصة في لوحة التحكم لإدخال اسم مستخدم تيك توك (`@username`) والاتصال المباشر بالبث بدون الحاجة لمفاتيح API معقدة.
   - استقبال لحظي لتعليقات الشات والهدايا وعدد المشاهدين.
2. **دعم TikFinity Webhooks**:
   - توفير رابط Webhook جاهز للاستخدام مع برامج TikFinity.
3. **محاكي أحداث مدمج (Event Simulator)**:
   - إمكانية تجربة اللعبة بالكامل دون فتح بث مباشر: توليد 10 لاعبين فوراً، محاكاة كتابة رقم الهدف بالشات، وإرسال هدايا الدفاع والعودة والمساعدة والحصانة بضغطة زر.
4. **عجلة روليت فيزيائية فائقة الواقعية (Canvas 2D)**:
   - دوران فيزيائي، تباطؤ تدريجي، أصوات نقرات المؤشر واصطدامه بالأسنان، وتوقف دقيق على اللاعب صاحب الدور.
5. **نظام التحذير والدفاع عن النفس (Gift Defense)**:
   - نافذة مواجهة كبرى (Selector VS Target).
   - مؤقت دائري مع أصوات نبضات القلب التحذيرية.
   - إلغاء الإقصاء فور وصول هدية الدفاع المحددة (افتراضياً وردة بقيمة 1 عملة).
   - إقصاء تلقائي عند انتهاء المؤقت ونقل اللاعب لقائمة المستبعدين.
6. **أنظمة العودة والمساعدة والحصانة**:
   - **العودة (Rejoin)**: إعادة اللاعب المستبعد فور إرسال هدية بقيمة 5 عملات.
   - **المساعدة (Help)**: إمكانية قيام أي مشاهد بإنقاذ لاعب مستبعد مقابل 16 عملة (ومنح المستفيد 5 عملات).
   - **الحصانة (Shield)**: شراء أو منح درع يحمي اللاعب من الاستهداف في الجولة.
7. **الحسم النهائي وتحديات الفائز (Final Round & Winner Challenge)**:
   - جولة الحسم مع مؤقت وهدايا الحسم.
   - منصة تتويج البطل ونظام تحدي البطل بهدايا التحدي.
8. **محرك أصوات مدمج (Web Audio API)**:
   - أصوات دوران العجلة، نقرات المؤشر، دقات المؤقت، صفارات الإنذار، وأبواق الفوز مولدة برمجياً 100% داخل المتصفح دون الحاجة لأي ملفات صوتية خارجية.

## 🚀 طريقة التشغيل السريعة

### 1. تثبيت الحزم وتشغيل السيرفر
في مجلد المشروع:
```bash
npm install
npm start
```
يعمل السيرفر افتراضياً على المنفذ `3001` (يمكن تغييره عبر متغير البيئة `PORT`).

### 2. فتح الروابط
- **شاشة العرض المخصصة للبث (Game Screen / Overlay)**:
  `http://localhost:3001/overlay`
  *(يتم وضع هذا الرابط كـ Browser Source في OBS بأبعاد 1920x1080)*
- **لوحة تحكم المدير (Admin Dashboard)**:
  `http://localhost:3001/admin`

### 3. الاختبارات
```bash
npm test              # جميع الاختبارات
npm run test:connector
npm run test:scenario
npm run test:http
```
الاختبارات تستخدم مجلد بيانات مؤقتاً ولا تلمس حالة اللعبة الحقيقية.

## 🌐 نشر الواجهة على GitHub Pages أو أي استضافة ثابتة

الواجهة (HTML/CSS/JS) تعمل وحدها، لكن اللعبة الحقيقية تحتاج خادم Node.js يعمل باستمرار
(Railway / Render / Fly.io / VPS). GitHub Pages لا يستطيع تشغيل الباك إند.

1. انشر مجلد المشروع على خادم Node (مثل Railway) باستخدام `node server/index.js`.
2. افتح لوحة التحكم أو شاشة البث، ثم في تبويب **ربط بث تيك توك** أدخل رابط الخادم في خانة
   **رابط خادم الباك إند (Backend URL)** واضغط **حفظ وإعادة الاتصال**.
3. يمكن أيضاً تمرير الرابط مباشرة في عنوان الصفحة:
   `https://gamvora.github.io/tiktokweb/?backend=https://your-app.up.railway.app`
   (يُحفظ تلقائياً في المتصفح).
4. بدون رابط خادم، تعمل الواجهة في **وضع Demo** للمعاينة فقط.

> ملاحظة: عند فتح الواجهة من نفس نطاق الخادم (Railway/Render) يتم اكتشاف العنوان تلقائياً.

## ⚙️ متغيرات البيئة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `3001` |
| `DATA_DIR` | مجلد حفظ حالة اللعبة والسجلات | `./data` |
| `FRONTEND_URL` | رابط الواجهة المسموح به في CORS | (غير مطلوب) |
| `EULER_API_KEY` | مفتاح EulerStream (اختياري) | (فارغ) |

## 📱 ربط البث المباشر

1. افتح لوحة التحكم `http://localhost:3001/admin`.
2. في خانة "اسم حساب تيك توك الخاص بصاحب البث"، اكتب اسم حسابك (مثال: `your_username`).
3. بعد فتح البث المباشر في تطبيق تيك توك، اضغط على زر **📡 اتصال بالبث المباشر**.
4. سيتحول المؤشر إلى **🟢 متصل بالبث المباشر** ويبدأ باستقبال تعليقات الشات وهدايا البث الحقيقية.
